# OBTC（Organic Bitcoin）创新分析

## 名字：为什么叫"有机比特币"

比特币是**无机的**——一个静态的、机械的系统：
- UTXO 一旦创建就永远存在，丢失的币永久占用状态空间
- 矿工收入依赖减半倒计时，终将归零
- UTXO 集只增不减，像一个只进不出的垃圾填埋场

OBTC 是**有机的**——一个活的、自我维持的系统：
- 资产拥有生命周期：诞生、使用、沉睡、到期、回收、再生
- 矿工收入有内生循环来源，不依赖减半时钟
- 状态通过自然回收自我清理，如同生态系统的物质循环

"Organic Bitcoin"不是"有机食品比特币"，而是**"活的比特币"**——一个有新陈代谢的比特币。

---

## 核心创新：不在技术，在经济模型

OBTC 使用的单项技术——UTXO 到期、MuHash 累加器、OP_RETURN 承诺、确定性交易构建——都是已知技术，没有密码学或协议层面的原创突破。

**创新在于将它们组合成一个自运转的经济系统。**

这和比特币本身的创新模式一样：哈希链、工作量证明、P2P 网络在中本聪之前都已存在。比特币的革命性在于将它们组装成了一个自洽的激励结构。OBTC 对比特币留下的未解问题做了同样的事：**谁来为永久状态存储付费？**

---

## 四大支柱

### 支柱一：存储成本显性化

比特币的隐含社会契约："你的 UTXO 永久免费存储，全球每一个全节点替你承担成本。"

UTXO 集小的时候这没问题。截至 2025 年，UTXO 集已超过 6-8 GB，且单调递增。估计有 300-400 万 BTC 已永久丢失——它们的 UTXO 将永远消耗节点存储空间，对网络的贡献为零。

OBTC 的回答：**如果你占用链上空间，就必须周期性地证明你仍在使用（移动你的币）。否则，网络回收资源。**

这不是充公——这是**状态租金**，和现实世界的房产税、云存储费用是同一原理。70% 退还原地址确保了所有者只要保持活跃，就能取回绝大部分价值。

### 支柱二：解决比特币的长期安全预算问题

比特币矿工收入模型：

```
区块奖励：  50 → 25 → 12.5 → 6.25 → 3.125 → ... → 0
交易手续费：必须以某种方式弥补不断下降的区块奖励
```

单靠交易手续费能否维持足够的算力安全，是**比特币最大的未解问题**。社区的态度一直是"以后再说"。

OBTC 给出了一个具体的替代方案：

```
OBTC 矿工收入 = 区块奖励 + 交易手续费 + REAP 税收（到期 UTXO 价值的 30%）
```

REAP 税收不是通胀——它将存量供应从沉睡持有者手中重新分配给活跃的网络参与者（矿工）。这创造了一个**永续收入流**，不依赖减半周期，也不依赖手续费市场。

### 支柱三：硬分叉继承带来的第一天经济活动

不同于从空白创世块开始的新链，OBTC 在分叉点继承比特币的完整 UTXO 集。到期窗口 `WindowBlocks = 362,880`（约 7 年）：

```
分叉高度：950,000
所有 CreateHeight <= 950,000 - 362,880 = 587,120 的 UTXO
→ 分叉第一天就已到期
```

587,120 高度大约对应 2019 年 8 月。**2019 年 8 月之前创建且从未移动过的全部 UTXO，在分叉第一天就可被 REAP。**

这包括：
- 中本聪估计约 100 万 BTC（从未移动）
- 已知丢失的币（估计 300-400 万 BTC）
- 从未花费的早期矿工奖励
- 多年交易产生的 dust 输出

保守估计：**分叉第一天就有 300-500 万 OBTC 对应的 UTXO 到期**，从第一个区块开始就产生 REAP 税收。

### 支柱四：面向 AI agent 的原生货币叙事

AI agent 带来一个传统金融体系很难解决的现实约束：**agent 不能自行完成 KYC，也不能走传统银行开户流程**，但它们会越来越多地承担支付算力、购买数据、执行预算、管理金库等任务。

这要求一种货币同时具备：

- 无许可持有与转移
- 机器可调用的钱包接口
- 可编排的权限和审计边界
- 对长期无人值守资产有生命周期管理

BTC 解决了"无需银行即可持有价值"的问题，但默认钱包模型仍以人类手工保管和偶发转账为中心。OBTC 则天然更接近 agent 的工作方式：它要求持续监控 UTXO 生命周期，而这正是 AI 擅长的事情。

项目的钱包方向也已经开始对齐这一点：现有 `obtcwallet` 已具备到期感知、续期、PSBT 和 agent 接口设计草案。换句话说，OBTC 不只是要解决"死币"问题，也在尝试成为一种**为未来 AI agent 经济设计的原生货币**。

## 飞轮效应：为什么这可能真的能跑起来

### 零成本挖矿期权

OBTC 使用 SHA-256，和比特币完全相同的 PoW 算法。矿工可以**零边际成本**合并挖矿：

- 同一台矿机、同一份电费
- 主挖 BTC 作为确定性收益
- 同时挖 OBTC 作为投机性收益——下行风险为零

这是一个**免费期权**。理性的矿工没有理由拒绝。这不是理论——BCH 和 BSV 分叉时矿工就是这样做的。

### 自我强化循环

```
零成本挖矿 → 矿工参与 → 算力安全保障
       ↓
历史到期 UTXO → 第一天起就有 REAP 税收 → 链上经济活动
       ↓
"回收中本聪的沉睡资产" → 叙事传播 → 投机定价
       ↓
OBTC 有了价格 → 矿工收益兑现 → 更多矿工 → 更强安全 → ...
```

如果再把 AI agent 的采用放进去，飞轮还会多出一层：

```
AI agent 需要无许可结算工具
      ↓
AI 钱包接入 OBTC，做续期/预算/审计自动化
      ↓
产生持续链上活跃度和真实支付需求
      ↓
OBTC 不再只有"回收叙事"，也有"机器经济使用场景"
```

没有任何其他比特币分叉同时具备这四个条件：
1. **零边际挖矿成本**（所有 SHA-256 分叉共有）
2. **即时经济活动**（OBTC 独有——第一天起就有 REAP）
3. **差异化经济叙事**（不是"更大的区块"或"不同的治理"，而是根本不同的可持续性模型）
4. **面向 AI 的钱包与货币方向**（让 lifecycle 成为机器可执行的资产管理系统）

## OBTC 提出的根本问题

> **"如果区块链存储不是免费的，应该由谁来付费？"**

比特币的回答："没有人——永远免费，节点自己扛。"

以太坊的探索：状态租金提案（EIP-4444、Verkle 树）讨论多年但从未落地。

OBTC 的回答：**"占用者付费，否则回收空间、循环利用。"**

这个回答在社会层面能否被接受，是市场要回答的问题。但 OBTC 是第一个把这个问题从论坛讨论变成**可运行的、共识强制执行的代码**的项目。

## 让项目更贴近 AI 的改进方向

如果要把"为 AI agent 设计的货币"从叙事变成产品，下一步最值得做的是：

- **正式化 Agent Wallet API**：把 `AgentWalletService`、gRPC/HTTP gateway、CLI 薄封装变成稳定主接口，而不是停留在草案或兼容层。
- **从全局解锁切到 capability 授权**：不要让 agent 拿到钱包口令后什么都能做，而是只给它特定账户、预算和动作范围。
- **拆分观察/规划/签名三层**：watch-only planner 负责同步链和生成 renewal/payment plan，signer 只做批准后的签名。
- **做事件驱动而不是 cron**：把 `utxo.expiring`、`renewal.failed`、`policy.fee_above_cap`、`reap_risk.elevated` 做成一等公民事件流。
- **引入多 agent 账户隔离**：至少区分 `treasury`、`renewal-agent`、`payments-agent`、`recovery-agent`，避免多个 agent 共用一个全能钱包。
- **把预演和审计做成默认路径**：所有 agent 操作都走 `preview -> approve -> sign -> publish`，并记录 `operation_id`、`capability_id`、`policy_version`、`decision_reason`。
- **优先验证真实 AI 支付场景**：例如算力结算、数据/API 购买、自动续期运维、链上资金库调度，而不只是演示 send/receive。

这些改进的共同点是：它们不是把"传统钱包接一层 AI"，而是把 OBTC 钱包真正做成一个**面向 agent 的资产生命周期控制系统**。

## 诚实评估

| 维度 | 评级 | 理由 |
|------|------|------|
| 技术原创性 | 中等 | 工程扎实，无新密码学原语 |
| 经济模型原创性 | 高 | 首个在比特币架构上实现状态租金的可运行系统 |
| 叙事强度 | 高 | "回收死去的比特币"有争议但有传播力 |
| 矿工参与门槛 | 极低 | SHA-256 零成本合并挖矿 |
| 用户采用门槛 | 极高 | 挑战比特币"你的币永远是你的"核心社会契约 |
| AI 延展性 | 高 | 生命周期资产 + 策略化钱包天然适合 agent 自动管理 |
| 长期意义 | 可能很高 | 可能影响比特币自身对安全预算可持续性的思考方向 |

### OBTC 不是什么

- 不是技术革命——使用的都是已知原语
- 不是比特币替代品——无法复制比特币的网络效应
- 不保证成功——社会共识是最难的问题

### OBTC 是什么

- 一个**可运行的概念验证**：证明 UTXO 到期在比特币架构上是可工程化的
- 一个**经济模型实验**：测试状态租金能否维持 PoW 安全
- 一个**对比特币的现实挑战**：质疑永久免费存储是否可持续
- 第一个从**第一天起就有内生链上经济活动**的比特币分叉
- 一个**面向 AI agent 时代的货币实验**：尝试把生命周期资产、策略钱包和机器经济结合起来

---

## 结论

OBTC 最深层的创新不在任何一段代码中。它在于认识到：一个真正可持续的区块链必须是**有机的**——能够循环利用自身资源，而不是无限积累状态、寄希望于经济问题自行解决。

如果再往前看一步，它也在提出另一个命题：**未来的货币，不一定只是给人类设计的，也可能要给 AI agent 设计。** 在这个意义上，OBTC 的生命周期模型和 AI 钱包路线并不是附属功能，而可能是它最有辨识度的长期方向。

市场是否认同这个论点是一个开放问题。但代码已经写完，共识规则已经生效，实验随时可以启动。
